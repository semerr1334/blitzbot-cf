# Cloudflare Workers — бесплатно, без карты, работает всегда

Плюсы: 0 ₽ навсегда, 100 000 запросов в день, не засыпает, сервер не нужен.
Минус: бот отвечает по webhook — код отдельный (`deploy/worker.js`), зато падать нечему.

## 1. Аккаунт

1. https://dash.cloudflare.com/sign-up — почта и пароль. **Карта не нужна.**
2. Слева **Workers & Pages** → **Create** → **Workers** → **Create Worker**.
3. Имя любое, например `blitzbot` → **Deploy**. Откроется редактор кода.

## 2. Код

1. В редакторе нажми **Edit code** (или сразу откроется).
2. Удали всё, что там есть, и вставь целиком содержимое файла **`deploy/worker.js`**
   (он уже собран из `kb.json`).
3. **Deploy**.

## 3. Настройки (Settings → Variables and Secrets)

Добавь четыре штуки. Первые две — как **Secret** (кнопка *Encrypt*), остальные можно как обычные:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | твой токен (Secret) |
| `WEBHOOK_SECRET` | любая строка, например `blitz-2026` (Secret) |
| `ADMIN_IDS` | твой user id (узнаешь командой `/id` в боте) |
| `ALLOWED_CHAT_IDS` | id чата скачавших; пусто = любой чат |
| `GITHUB_TOKEN` | read-only токен GitHub, чтобы бот видел приватные логи (Secret) |

После добавления — **Deploy** ещё раз.

## 4. Включить webhook (один раз)

Открой в браузере:

```
https://blitzbot.<твой-поддомен>.workers.dev/?set=1
```

Должно ответить `{"ok":true,...}`. Проверка:

```
https://blitzbot.<твой-поддомен>.workers.dev/?info=1
```

Покажет версию релиза, число тем и что секрет задан.

## 5. Проверить в чате

Напиши боту `/start`, потом «улетаю за карту» — должен ответить и дать ссылку.
В группе: `/id` → пришлёт `chat_id`; впиши его в `ALLOWED_CHAT_IDS`, если хочешь
ограничить бота своими чатами.

## Обновление базы знаний

```bash
python3 tools/make_worker.py     # пересобирает deploy/worker.js из kb.json
```

Дальше — скопировать новый `deploy/worker.js` в редактор и **Deploy**.

## Ограничения бесплатного тарифа

- 100 000 запросов в день (одно сообщение = 1 запрос) — это десятки тысяч сообщений.
- 10 мс процессорного времени на запрос — наш бот укладывается (сеть не считается).
- Место под состояние не нужно: webhook не требует `offset`, как polling.
